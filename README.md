# nishannorunobi.github.io

Personal research website of **Norun Nabi** — doctoral researcher in computer science (cybersecurity, machine learning, applied AI).

Live at **https://nishannorunobi.github.io**, served free by GitHub Pages.

- Pages: `_pages/` (About, Research & Service, CV) · Publications: one file per paper in `_publications/`
- CV PDF: `files/Norun_Nabi_CV.pdf`
- Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template (MIT licence, see `LICENSE`).

Local preview: `docker compose up` → http://localhost:4000
